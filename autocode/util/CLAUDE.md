# util/

Standalone helpers not tied to an SDLC phase: documentation lookup, generic utilities, and other agents that other skills delegate to without belonging to a specific workflow. Add a skill or agent here only when no SDLC-phase feature-set fits.

Deliberately a mixed bucket: its members share no domain, only the "not phase-specific" property. Today that is the `handover` skill and the `claude-code-guide` agent.
